# SEO Meta Auditor

Массовая проверка мета-тегов и заголовков сайта по списку URL или sitemap.xml с отчётом в браузере и выгрузкой в Excel.

## Проблема

Проверка title, description, H1, canonical и кодов ответа — ежедневная рутина SEO-специалиста: при запуске проекта, после правок на сайте, перед сдачей отчёта клиенту. Вручную (открыть страницу → «посмотреть код» → скопировать теги в таблицу) это занимает часы на сайт из 100 страниц, а ошибки (дубли title, пропущенный H1, случайный noindex, 404 в sitemap) прямо влияют на позиции. Универсальные краулеры (Screaming Frog) избыточны для быстрой проверки, а бесплатная версия ограничена 500 URL и тяжела для клиентов и коллег без SEO-опыта.

## Пользователь

SEO-специалисты, контент-менеджеры и владельцы сайтов, которым нужно быстро получить список технических проблем страниц без установки тяжёлого софта.

## Основная функция

**Вход:** список URL (по одному в строке) или адрес `sitemap.xml` (включая вложенные индексы).

**Обработка:** параллельная загрузка страниц (8 потоков), извлечение `title`, `meta description`, `H1`, `canonical`, `meta robots`, кода ответа; применение правил проверки:

| Уровень | Правило |
|---|---|
| Критично | страница недоступна / код 4xx–5xx, нет title, дубль title, нет H1, noindex |
| Предупреждение | title вне 30–65 символов, description отсутствует или вне 70–165 символов, дубль description, несколько H1 |
| Замечание | нет canonical |

**Выход:** таблица с цветовой разметкой и счётчиками проблем в браузере + файл `seo_audit.xlsx`.

## Формат результата

- Веб-страница: сводка (проверено / критичные / предупреждения / замечания / без проблем) и таблица по каждому URL с тегами проблем.
- Excel-файл: все данные, длины title и description, колонка «Проблемы» с цветовой заливкой, закреплённая шапка.

## Минимальный функционал (MVP)

- Ввод списка URL или sitemap.xml, лимит 200 страниц за проверку
- Проверка по правилам выше
- Отчёт на странице и выгрузка в Excel

**В планах:** сравнение с предыдущей проверкой, проверка ключевых слов в title/H1, Open Graph и schema.org, проверка внутренних ссылок и редиректов, сохранение истории, публикация на VPS.

**Ограничения:** страницы, формируемые JavaScript, не рендерятся (читается только исходный HTML); результат последней проверки хранится в файле `results/` 24 часа и привязан к cookie-сессии пользователя.

**Безопасность:** сервис блокирует запросы к localhost и внутренним адресам (защита от SSRF), разрешены только порты 80 и 443. При публикации в интернет обязательна авторизация (Basic Auth).

## Технологии

Python 3.10+, Flask, requests, BeautifulSoup4 + lxml, openpyxl, HTML/CSS (без внешних зависимостей на фронтенде).

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000 (локально пароль не нужен).

## Публикация на сервере (App Platform, Gunicorn)

1. Тип приложения Flask, Python 3.10+.
2. Команда запуска: `gunicorn app:app --bind 0.0.0.0:$PORT --workers 2 --timeout 120`
3. Переменные окружения: `APP_USER`, `APP_PASSWORD` (без пароля сервис отвечает 503), `SECRET_KEY` (длинная случайная строка).
4. Для локального пароля скопируйте `config_local.example.py` в `config_local.py`.

## Сценарий использования

1. Вставьте URL страниц сайта или адрес `https://site.ru/sitemap.xml`.
2. Нажмите «Проверить».
3. Посмотрите сводку и отсортируйте внимание по цветам: красные строки — исправлять первыми.
4. Нажмите «Скачать Excel» и передайте файл разработчику или клиенту.
